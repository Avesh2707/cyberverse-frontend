# OPENLABS Frontend

Modern React frontend for OPENLABS Cybersecurity Learning Platform.

## Setup

```bash
# 1. Install dependencies
npm install

# 2. Make sure backend is running on port 5000
# npm run dev (in backend folder)

# 3. Start frontend
npm start
```

Opens at: http://localhost:3000

## Pages
- /login — Login
- /register — Register  
- /dashboard — Main dashboard
- /domains — All security domains
- /domains/:slug — Domain challenges
- /practice — Random practice challenges
- /compete — Competitive challenges
- /leaderboard — Global rankings
- /news — CTF news & live events
- /profile — User profile & badges
